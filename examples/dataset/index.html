Query a dataset of any size, in the browser

A .vectro dataset is read in pieces: from a URL with HTTP range requests, from a file on this computer, or from the browser's own storage. Only the chunks and columns a query needs are read, so a file far bigger than the browser's memory works.

The CSV is read in pieces and written to this browser's storage (it never has to fit in memory).
